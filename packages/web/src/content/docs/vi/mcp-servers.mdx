title: MCP servers
description: Thêm công cụ MCP cục bộ và từ xa.
---

Bạn có thể thêm công cụ bên ngoài vào OpenCode bằng _Model Context Protocol_, hay MCP. OpenCode hỗ trợ cả server cục bộ và server từ xa.

Sau khi được thêm, MCP tools sẽ tự động có sẵn cho LLM cùng với built-in tools.

---

#### Lưu ý

Khi bạn dùng một MCP server, nó sẽ thêm vào context. Phần này có thể tăng rất nhanh nếu bạn có nhiều tool. Vì vậy chúng tôi khuyên bạn cẩn thận với những MCP server mình dùng.

:::tip
MCP servers thêm vào context của bạn, nên bạn cần cẩn thận với những server được bật.
:::

Một số MCP server, như GitHub MCP server, thường thêm rất nhiều token và có thể dễ dàng vượt quá giới hạn context.

---

## Bật

Bạn có thể định nghĩa MCP servers trong [OpenCode Config](https://opencode.ai/docs/config/) dưới `mcp`. Thêm mỗi MCP với một tên duy nhất. Bạn có thể nhắc đến MCP đó theo tên khi prompt LLM.

```jsonc title="opencode.jsonc" {6}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "name-of-mcp-server": {
      // ...
      "enabled": true,
    },
    "name-of-other-mcp-server": {
      // ...
    },
  },
}
```

Bạn cũng có thể tắt một server bằng cách đặt `enabled` thành `false`. Điều này hữu ích nếu bạn muốn tạm thời tắt server mà không xóa nó khỏi config.

---

### Ghi đè mặc định từ xa

Các tổ chức có thể cung cấp MCP servers mặc định qua endpoint `.well-known/opencode` của họ. Các server này có thể bị tắt theo mặc định, cho phép người dùng opt-in những server họ cần.

Để bật một server cụ thể từ remote config của tổ chức, hãy thêm nó vào local config với `enabled: true`:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "jira": {
      "type": "remote",
      "url": "https://jira.example.com/mcp",
      "enabled": true
    }
  }
}
```

Các giá trị local config của bạn ghi đè remote defaults. Xem [config precedence](/docs/config#precedence-order) để biết thêm chi tiết.

---

## Local

Thêm local MCP servers bằng cách đặt `type` thành `"local"` trong MCP object.

```jsonc title="opencode.jsonc" {15}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-local-mcp-server": {
      "type": "local",
      // Or ["bun", "x", "my-mcp-command"]
      "command": ["npx", "-y", "my-mcp-command"],
      "enabled": true,
      "environment": {
        "MY_ENV_VAR": "my_env_var_value",
      },
    },
  },
}
```

Command là cách local MCP server được khởi động. Bạn cũng có thể truyền vào danh sách biến môi trường.

Ví dụ, đây là cách bạn có thể thêm MCP server test [`@modelcontextprotocol/server-everything`](https://www.npmjs.com/package/@modelcontextprotocol/server-everything).

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mcp_everything": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
    },
  },
}
```

Và để dùng nó, tôi có thể thêm `use the mcp_everything tool` vào prompts của mình.

```txt "mcp_everything"
use the mcp_everything tool to add the number 3 and 4
```

---

#### Tùy chọn

Đây là tất cả options để cấu hình một local MCP server.

| Tùy chọn      | Kiểu    | Bắt buộc | Mô tả                                                                                     |
| ------------- | ------- | -------- | ----------------------------------------------------------------------------------------- |
| `type`        | String  | Y        | Kiểu kết nối MCP server, phải là `"local"`.                                               |
| `command`     | Array   | Y        | Lệnh và tham số để chạy MCP server.                                                       |
| `cwd`         | String  |          | Thư mục làm việc cho process MCP server. Đường dẫn tương đối resolve từ workspace.        |
| `environment` | Object  |          | Biến môi trường cần đặt khi chạy server.                                                  |
| `enabled`     | Boolean |          | Bật hoặc tắt MCP server khi khởi động.                                                     |
| `timeout`     | Number  |          | Timeout tính bằng ms khi lấy tools từ MCP server. Mặc định là 5000 (5 giây).              |

## Remote

Thêm remote MCP servers bằng cách đặt `type` thành `"remote"`.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-remote-mcp": {
      "type": "remote",
      "url": "https://my-mcp-server.com",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer MY_API_KEY"
      }
    }
  }
}
```

`url` là URL của remote MCP server và với option `headers`, bạn có thể truyền vào danh sách headers.

---

#### Tùy chọn

| Tùy chọn  | Kiểu    | Bắt buộc | Mô tả                                                                                    |
| --------- | ------- | -------- | ---------------------------------------------------------------------------------------- |
| `type`    | String  | Y        | Kiểu kết nối MCP server, phải là `"remote"`.                                             |
| `url`     | String  | Y        | URL của remote MCP server.                                                               |
| `enabled` | Boolean |          | Bật hoặc tắt MCP server khi khởi động.                                                    |
| `headers` | Object  |          | Headers để gửi cùng request.                                                             |
| `oauth`   | Object  |          | Cấu hình xác thực OAuth. Xem phần [OAuth](#oauth) bên dưới.                              |
| `timeout` | Number  |          | Timeout tính bằng ms khi lấy tools từ MCP server. Mặc định là 5000 (5 giây).             |

## OAuth

OpenCode tự động xử lý xác thực OAuth cho remote MCP servers. Khi một server yêu cầu xác thực, OpenCode sẽ:

1. Phát hiện response 401 và khởi tạo OAuth flow
2. Dùng **Dynamic Client Registration (RFC 7591)** nếu server hỗ trợ
3. Lưu token an toàn cho các request sau này

---

### Tự động

Với hầu hết MCP server hỗ trợ OAuth, không cần cấu hình đặc biệt. Chỉ cần cấu hình remote server:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp"
    }
  }
}
```

Nếu server yêu cầu xác thực, OpenCode sẽ nhắc bạn xác thực khi bạn thử dùng nó lần đầu. Nếu không, bạn có thể [kích hoạt flow thủ công](#authenticating) bằng `opencode mcp auth <server-name>`.

---

### Đăng ký sẵn

Nếu bạn có client credentials từ provider của MCP server, bạn có thể cấu hình chúng:

```json title="opencode.json" {7-11}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": {
        "clientId": "{env:MY_MCP_CLIENT_ID}",
        "clientSecret": "{env:MY_MCP_CLIENT_SECRET}",
        "scope": "tools:read tools:execute"
      }
    }
  }
}
```

---

### Authenticating

Bạn có thể kích hoạt xác thực thủ công hoặc quản lý credentials.

Xác thực với một MCP server cụ thể:

```bash
opencode mcp auth my-oauth-server
```

Liệt kê tất cả MCP servers và trạng thái auth của chúng:

```bash
opencode mcp list
```

Xóa credentials đã lưu:

```bash
opencode mcp logout my-oauth-server
```

Lệnh `mcp auth` sẽ mở trình duyệt của bạn để authorize. Sau khi bạn authorize, OpenCode sẽ lưu token an toàn trong `~/.local/share/opencode/mcp-auth.json`.

---

#### Tắt OAuth

Nếu bạn muốn tắt OAuth tự động cho một server (ví dụ server dùng API keys), đặt `oauth` thành `false`:

```json title="opencode.json" {7}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-api-key-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": false,
      "headers": {
        "Authorization": "Bearer {env:MY_API_KEY}"
      }
    }
  }
}
```

---

#### Tùy chọn OAuth

| Tùy chọn       | Kiểu            | Mô tả                                                                                        |
| -------------- | --------------- | -------------------------------------------------------------------------------------------- |
| `oauth`        | Object \| false | Object cấu hình OAuth, hoặc `false` để tắt tự động phát hiện OAuth.                          |
| `clientId`     | String          | OAuth client ID. Nếu không cung cấp, dynamic client registration sẽ được thử.                 |
| `clientSecret` | String          | OAuth client secret, nếu authorization server yêu cầu.                                       |
| `scope`        | String          | OAuth scopes cần request trong quá trình authorization.                                      |

#### Debugging

Nếu một remote MCP server xác thực thất bại, bạn có thể chẩn đoán vấn đề bằng:

```bash
# View auth status for all OAuth-capable servers
opencode mcp auth list

# Debug connection and OAuth flow for a specific server
opencode mcp debug my-oauth-server
```

Lệnh `mcp debug` hiển thị trạng thái auth hiện tại, kiểm tra kết nối HTTP, và thử OAuth discovery flow.

## Quản lý

MCP của bạn có sẵn như tools trong OpenCode, cùng với built-in tools. Vì vậy bạn có thể quản lý chúng qua OpenCode config giống như bất kỳ tool nào khác.

---

### Global

Điều này nghĩa là bạn có thể bật hoặc tắt chúng ở phạm vi global.

```json title="opencode.json" {14}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp-foo": false
  }
}
```

Chúng ta cũng có thể dùng glob pattern để tắt tất cả MCP khớp.

```json title="opencode.json" {14}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp*": false
  }
}
```

Ở đây chúng ta dùng glob pattern `my-mcp*` để tắt tất cả MCP.

---

### Theo từng agent

Nếu bạn có số lượng lớn MCP servers, bạn có thể chỉ bật chúng theo từng agent và tắt global. Để làm việc này:

1. Tắt nó như một tool ở global.
2. Trong [agent config](/docs/agents#tools), bật MCP server như một tool.

```json title="opencode.json" {11, 14-18}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-mcp": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command"],
      "enabled": true
    }
  },
  "tools": {
    "my-mcp*": false
  },
  "agent": {
    "my-agent": {
      "tools": {
        "my-mcp*": true
      }
    }
  }
}
```

---

#### Glob patterns

Glob pattern dùng các regex globbing pattern đơn giản:

- `*` khớp với không hoặc nhiều ký tự bất kỳ (ví dụ, `"my-mcp*"` khớp `my-mcp_search`, `my-mcp_list`, v.v.)
- `?` khớp đúng một ký tự
- Tất cả ký tự khác khớp theo nghĩa literal

:::note
MCP server tools được đăng ký với tên server làm prefix, nên để tắt tất cả tools của một server, chỉ cần dùng:

```
"mymcpservername_*": false
```

:::

## Ví dụ

Dưới đây là ví dụ về một số MCP servers phổ biến. Bạn có thể gửi PR nếu muốn document server khác.

---

### Sentry

Thêm [Sentry MCP server](https://mcp.sentry.dev) để tương tác với các dự án và issues Sentry của bạn.

```json title="opencode.json" {4-8}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "sentry": {
      "type": "remote",
      "url": "https://mcp.sentry.dev/mcp",
      "oauth": {}
    }
  }
}
```

Sau khi thêm cấu hình, xác thực với Sentry:

```bash
opencode mcp auth sentry
```

Lệnh này sẽ mở cửa sổ trình duyệt để hoàn tất OAuth flow và kết nối OpenCode với tài khoản Sentry của bạn.

Sau khi xác thực, bạn có thể dùng Sentry tools trong prompts để query issues, projects, và error data.

```txt "use sentry"
Show me the latest unresolved issues in my project. use sentry
```

---

### Context7

Thêm [Context7 MCP server](https://github.com/upstash/context7) để tìm kiếm trong docs.

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp"
    }
  }
}
```

Nếu bạn đã đăng ký tài khoản miễn phí, bạn có thể dùng API key của mình để có rate-limit cao hơn.

```json title="opencode.json" {7-9}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
      }
    }
  }
}
```

Ở đây chúng ta giả định bạn đã đặt biến môi trường `CONTEXT7_API_KEY`.

Thêm `use context7` vào prompts để dùng Context7 MCP server.

```txt "use context7"
Configure a Cloudflare Worker script to cache JSON API responses for five minutes. use context7
```

Ngoài ra, bạn có thể thêm nội dung kiểu này vào [AGENTS.md](/docs/rules/).

```md title="AGENTS.md"
When you need to search docs, use `context7` tools.
```

---

### Grep by Vercel

Thêm [Grep by Vercel](https://grep.app) MCP server để tìm kiếm code snippets trên GitHub.

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "gh_grep": {
      "type": "remote",
      "url": "https://mcp.grep.app"
    }
  }
}
```

Vì chúng ta đặt tên MCP server là `gh_grep`, bạn có thể thêm `use the gh_grep tool` vào prompts để agent dùng nó.

```txt "use the gh_grep tool"
What's the right way to set a custom domain in an SST Astro component? use the gh_grep tool
```

Ngoài ra, bạn có thể thêm nội dung kiểu này vào [AGENTS.md](/docs/rules/).

```md title="AGENTS.md"
If you are unsure how to do something, use `gh_grep` to search code examples from GitHub.
```
