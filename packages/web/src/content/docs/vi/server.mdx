Lệnh `opencode serve` chạy một HTTP server headless, cung cấp endpoint OpenAPI mà opencode client có thể dùng.

---

### Cách dùng

```bash
opencode serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### Tùy chọn

| Flag            | Mô tả                                  | Mặc định         |
| --------------- | --------------------------------------- | ---------------- |
| `--port`        | Port để listen                          | `4096`           |
| `--hostname`    | Hostname để listen                      | `127.0.0.1`      |
| `--mdns`        | Bật mDNS discovery                      | `false`          |
| `--mdns-domain` | Tên domain tùy chỉnh cho mDNS service   | `opencode.local` |
| `--cors`        | Browser origins bổ sung được cho phép   | `[]`             |

`--cors` có thể được truyền nhiều lần:

```bash
opencode serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### Xác thực

Đặt `OPENCODE_SERVER_PASSWORD` để bảo vệ server bằng HTTP basic auth. Username mặc định là `opencode`, hoặc đặt `OPENCODE_SERVER_USERNAME` để ghi đè. Điều này áp dụng cho cả `opencode serve` và `opencode web`.

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve
```

---

### Cách hoạt động

Khi bạn chạy `opencode`, nó khởi động một TUI và một server. TUI là
client nói chuyện với server. Server cung cấp một endpoint OpenAPI 3.1 spec.
Endpoint này cũng được dùng để tạo [SDK](/docs/sdk).

:::tip
Dùng opencode server để tương tác với opencode bằng lập trình.
:::

Kiến trúc này cho phép opencode hỗ trợ nhiều client và cho phép bạn tương tác với opencode bằng lập trình.

Bạn có thể chạy `opencode serve` để khởi động một standalone server. Nếu bạn đang chạy
opencode TUI, `opencode serve` sẽ khởi động một server mới.

---

#### Kết nối tới server hiện có

Khi bạn khởi động TUI, nó gán ngẫu nhiên một port và hostname. Thay vào đó, bạn có thể truyền các [flags](/docs/cli) `--hostname` và `--port`. Sau đó dùng thông tin này để kết nối tới server của nó.

Endpoint [`/tui`](#tui) có thể được dùng để điều khiển TUI thông qua server. Ví dụ, bạn có thể điền sẵn hoặc chạy một prompt. Thiết lập này được dùng bởi các plugin [IDE](/docs/ide) của OpenCode.

---

## Spec

Server publish một OpenAPI 3.1 spec có thể xem tại:

```
http://<hostname>:<port>/doc
```

Ví dụ, `http://localhost:4096/doc`. Dùng spec để tạo clients hoặc kiểm tra kiểu request và response. Hoặc xem nó trong Swagger explorer.

### Files

| Method | Path                     | Mô tả                                    | Response                                                                                    |
| ------ | ------------------------ | ---------------------------------------- | ------------------------------------------------------------------------------------------- |
| `GET`  | `/find?pattern=<pat>`    | Tìm text trong files                     | Array of match objects with `path`, `lines`, `line_number`, `absolute_offset`, `submatches` |
| `GET`  | `/find/file?query=<q>`   | Tìm files và directories theo tên        | `string[]` (paths)                                                                          |
| `GET`  | `/find/symbol?query=<q>` | Tìm workspace symbols                    | <a href={typesUrl}><code>Symbol[]</code></a>                                                |
| `GET`  | `/file?path=<path>`      | Liệt kê files và directories             | <a href={typesUrl}><code>FileNode[]</code></a>                                              |
| `GET`  | `/file/content?path=<p>` | Đọc một file                             | <a href={typesUrl}><code>FileContent</code></a>                                             |
| `GET`  | `/file/status`           | Lấy trạng thái tracked files             | <a href={typesUrl}><code>File[]</code></a>                                                  |

#### `/find/file` query parameters

- `query` (required) — chuỗi tìm kiếm (fuzzy match)
- `type` (optional) — giới hạn kết quả thành `"file"` hoặc `"directory"`
- `directory` (optional) — ghi đè project root cho tìm kiếm
- `limit` (optional) — số kết quả tối đa (1–200)
- `dirs` (optional) — legacy flag (`"false"` chỉ trả về files)
