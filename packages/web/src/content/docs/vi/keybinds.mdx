:::note
Trên Windows, mặc định của `input_undo` và `terminal_suspend` khác nhau:

- `input_undo` mặc định là `ctrl+z,ctrl+-,super+z` khi không được cấu hình rõ ràng. Binding `ctrl+z` được thêm vì terminal Windows không hỗ trợ POSIX suspend.
- `terminal_suspend` bị buộc thành `none` vì terminal Windows gốc không hỗ trợ POSIX suspend.
  :::

## Phím Leader

OpenCode dùng phím `leader` cho nhiều phím tắt. Điều này tránh xung đột trong terminal của bạn.

Theo mặc định, `ctrl+x` là phím leader và nhiều hành động yêu cầu bạn nhấn phím leader trước rồi nhấn phím tắt. Ví dụ, để bắt đầu một phiên mới, trước tiên bạn nhấn `ctrl+x`, rồi nhấn `n`.

Bạn không bắt buộc phải dùng phím leader cho các phím tắt của mình, nhưng chúng tôi khuyên nên làm vậy.

Một số phím tắt điều hướng cố ý không dùng phím leader theo mặc định. Với phiên subagent, mặc định là `session_child_first` = `<leader>down`, `session_child_cycle` = `right`, `session_child_cycle_reverse` = `left`, và `session_parent` = `up`.

`leader_timeout` kiểm soát OpenCode chờ phím tiếp theo trong bao lâu sau phím leader. Mặc định là `2000` mili giây.

## Giá trị binding

Một chuỗi có thể chứa một phím tắt hoặc nhiều phím tắt phân tách bằng dấu phẩy. Bạn cũng có thể dùng array cho nhiều phím tắt.

Với các trường hợp nâng cao, dùng một object có `key`, `event`, `preventDefault`, hoặc `fallthrough`.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "messages_copy": ["<leader>y", "ctrl+shift+c"],
    "input_paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

## Tắt phím tắt

Bạn có thể tắt một phím tắt bằng cách thêm khóa đó vào `tui.json` với giá trị `"none"` hoặc `false`.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "session_compact": "none"
  }
}
```

## Phím tắt prompt trên desktop

Ô nhập prompt của ứng dụng desktop OpenCode hỗ trợ các phím tắt chỉnh sửa văn bản phổ biến theo kiểu Readline/Emacs. Chúng được tích hợp sẵn và hiện chưa thể cấu hình qua `opencode.json`.

| Shortcut | Action                                  |
| -------- | --------------------------------------- |
| `ctrl+a` | Di chuyển tới đầu dòng hiện tại         |
| `ctrl+e` | Di chuyển tới cuối dòng hiện tại        |
| `ctrl+b` | Lùi con trỏ lại một ký tự               |
| `ctrl+f` | Tiến con trỏ lên một ký tự              |
| `alt+b`  | Lùi con trỏ lại một từ                  |
| `alt+f`  | Tiến con trỏ lên một từ                 |
| `ctrl+d` | Xóa ký tự dưới con trỏ                  |
| `ctrl+k` | Xóa tới cuối dòng                       |
| `ctrl+u` | Xóa tới đầu dòng                        |
| `ctrl+w` | Xóa từ phía trước                       |
| `alt+d`  | Xóa từ tiếp theo                        |
| `ctrl+t` | Hoán đổi ký tự                          |
| `ctrl+g` | Hủy popover / hủy phản hồi đang chạy    |

## Shift+Enter

Một số terminal không gửi phím bổ trợ cùng Enter theo mặc định. Bạn có thể cần cấu hình terminal để gửi `Shift+Enter` dưới dạng escape sequence.

### Windows Terminal

Mở `settings.json` tại:

```
%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json
```

Thêm phần này vào array `actions` ở cấp root:

```json
"actions": [
  {
    "command": {
      "action": "sendInput",
      "input": "\u001b[13;2u"
    },
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Thêm phần này vào array `keybindings` ở cấp root:

```json
"keybindings": [
  {
    "keys": "shift+enter",
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Lưu tệp và khởi động lại Windows Terminal hoặc mở tab mới.
